# C++ Image Processing Project

A C++ image processing application developed as part of Programming Fundamentals II at the University of Florida.

## Overview

This project demonstrates object-oriented programming, binary file handling, and pixel-level image manipulation using the TGA image format.

## Features

- Read and write TGA image files
- Perform pixel-level image manipulation
- Apply image blending operations, including Multiply, Screen, Subtract, and Overlay
- Adjust image color channels and intensity
- Flip images and combine image data
- Process images using command-line operations

## Technologies

- **Language:** C++
- **Concepts:** Object-Oriented Programming, Binary File I/O, Image Processing
- **Build Tool:** Make

## Building the Project

Clone the repository and build the application:

```bash
git clone https://github.com/kosuho5-hue/cpp-image-processing.git
cd cpp-image-processing
make
```
